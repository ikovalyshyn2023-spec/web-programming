# Мої 3 найкращі міста світу

Статичний багатосторінковий web-блог, створений у рамках **Лабораторної роботи 1** з дисципліни «WEB-програмування».

## Тема
Імплементація блогу «Мої 3 найкращі міста світу» з використанням семантичної HTML-розмітки, організація проєкту в Git-репозиторії, розміщення на GitHub та розгортання за допомогою GitHub Pages.

## Структура проєкту

```
my-best-cities/
├── index.html          # Головна сторінка
├── city-kyiv.html      # Сторінка міста Київ
├── city-paris.html     # Сторінка міста Париж
├── city-tokyo.html     # Сторінка міста Токіо
├── form.html           # Форма «Запропонувати місто»
├── images/             # Зображення міст
│   ├── kyiv.jpg
│   ├── paris.jpg
│   └── tokyo.jpg
└── README.md           # Опис проєкту
```

## Обрані міста
1. **Київ** (Україна)
2. **Париж** (Франція)
3. **Токіо** (Японія)

## Технології
- HTML5 (семантична розмітка)
- Git / GitHub
- GitHub Pages

## Як запустити локально
1. Клонуйте репозиторій або завантажте файли.
2. Відкрийте `index.html` у браузері.

## Deployment
Сайт опубліковано за допомогою **GitHub Pages**.

Посилання на живий сайт:  
`https://ВАШ_USERNAME.github.io/my-best-cities/`
