Моніторинг шуму з API (TypeScript)

Дані сенсорів завантажуються з MockAPI через fetch() і типізуються інтерфейсом Sensor.

Активні сенсори

Список будується динамічно після GET-запиту. Код написаний на TypeScript і скомпільований у dist/sensors.js.

Ланцюжок роботи

  1. MockAPI зберігає JSON-масив сенсорів
  2. fetch(API_URL) — HTTP GET
  3. response.json() → Sensor[]
  4. renderSensors(sensors) — картки в DOM
